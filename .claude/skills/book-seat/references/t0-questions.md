# T0: questions to grill the owner on (one at a time, recommend an answer each time)

1. The book: title, edition, file name on the VPS, page count. Is it the owner's own copy?
2. Authors: who wrote which parts (main text, commentary, footnotes, foreword)? These become the `author` labels; the
   seat keeps each author's words apart.
3. Structure: does the heading detector fit, or do we write `structure.json` by hand (id, title, author, start, end)?
4. Seat: key (short, lowercase), name, short name, pillar, the one question it owns, dimension; on call or default board;
   which seats it will clash with and over what.
5. Investing book? If yes, T8 runs: which companies (good, bad, and a scan), the label rules, the prediction, written
   before any score (PREREG). If no, skip T8 or name a test decision.
6. Pass rule: keep the default (`pass-rule.md`) or change a bar?
7. Models: keep the defaults (`models.md`)?
8. Public material about the author beside the book? Off by default; it is a fetch (stop point 6).
9. Portrait: book-style image via `/newroaster portrait` if a kie.ai key exists; otherwise the placeholder.
