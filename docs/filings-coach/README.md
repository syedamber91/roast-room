# Filings coach

The leveled framework for reading a listed Indian company's own documents (8 levels, 278 steps), every
source it was built from, the 6,728 extracted checks and the pipeline that grows it all live in the
private repo **syedamber91/learning-vault-invest**, folder `filings-coach/`. They are kept private
because the framework is built from the licensed SOIC course and from books and documents that are free
to read but not free to redistribute.

This public repo holds only the council seat that uses the framework (`council-coach`). When the private
repo is checked out next to this one (`../learning-vault-invest`), the seat reads the full framework and
opens the exact source page behind any claim; without it, the seat says so and cites document, page and
URL instead.

The scripts that were here earlier moved to `learning-vault-invest/filings-coach/pipeline/`.
